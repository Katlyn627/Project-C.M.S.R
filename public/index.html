Project C.M.S.R

Community Mentorship & Safe Route Volunteer Coordinator. A platform connecting community volunteers with local youth centers and schools.

🩺 View /health Status 📂 GitHub Repository

🚶‍♀️ Safe Route Rosters

Manage weekly walking-bus routes, after-school tutoring, and mentorship sessions with volunteer capacity enforcement.

🛡️ Safeguarding

Secure incident logging with AES-256-GCM encryption at rest, role-based decryption, and automated coordinator escalation alerts.

📱 SMS & USSD Gateway

Automated shift reminders, safe arrival confirmations for parents, and simulated USSD callback sessions for low-connectivity regions.

Core API Endpoints

GET /health Service health status
POST /auth/register Register user (admin, coordinator, volunteer, viewer)
POST /auth/login Authenticate user & receive JWT
GET /volunteers List volunteer profiles (coordinator+)
GET /shifts List walking bus and mentorship shifts
POST /incidents Report safeguarding incident (AES-256 encrypted)
POST /sms/safe-arrival Send arrival notification to parents
